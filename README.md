# Windows 目录结构

本仓库记录本机 Windows 系统的磁盘目录结构，范围为 D、E、F 三个盘。C 盘为系统盘，不在此记录。

## 硬件

两块 512G 固态硬盘，划分为 C、D、E、F 四个分区。

## 磁盘总览

| 盘符 | 定位 |
| --- | --- |
| C | 系统盘（不记录） |
| D | 环境与软件 |
| E | 工作区 |
| F | 下载与学习 |

## D 盘 —— 环境与软件

```
D:\
├── Environments\        运行环境与底层资源
├── Softwares\           应用软件
```
